# Coffee Cellar

iPhoneで長期保管中のコーヒー豆を管理する個人用Webアプリです。ビルド不要のHTML / CSS / JavaScriptで動き、データは端末のIndexedDBに保存します。

## 現在の状態

**ロードマップの段階2まで実装済み。** 在庫管理、プリセット管理、期間フィルター、JSONバックアップ・復元を利用できます。iPhone実機のファイル保存・読込はまだ未検証です。

実装済み：

- 豆の追加・一覧・詳細・編集
- 写真のメニュー9種類の初期プリセット選択、設定から追加・編集・削除
- 半年（180日）・1年（365日）・1年半（548日）以上の期間フィルター
- 全データのJSON書き出し、内容確認付きの全置換復元
- 焙煎度1〜5と自由入力、焙煎日の入力検証
- 正確な暦日差、月末を考慮した経過年月、古い順の表示
- 飲み終わり、アーカイブ一覧、確認付きの完全削除
- 同じ豆の複数袋登録、再読み込み後のデータ保持
- 未保存変更の破棄確認、保存失敗時の入力保持
- iPhoneサイズを考慮した下部タブ、safe area、キーボード操作

次の段階：CSV、manifest・Service Worker、オフライン起動。その後にGitHub Pages公開とiPhone実機検証を進めます。ホーム画面追加用のPWA設定に対応しました。オフライン起動は未対応です。

## ローカルで開く

このフォルダで次を実行します。Python 3があればアプリの起動にnpmの依存取得は不要です。

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

ブラウザで [Coffee Cellar](http://127.0.0.1:4173/) を開きます。Node.jsを使う場合は `npm start` でも同じサーバーが起動します。終了はターミナルでCtrl+Cを押します。

`index.html`をファイルとして直接開かず、HTTPサーバーから利用してください。ブラウザ・ホスト名・ポートが変わると保存領域も変わるため、普段の試用には同じURLを使います。テスト用サーバーは別ポート4174で起動し、試用データと分離します。

## プリセットとバックアップの使い方

設定の「プリセットを管理」から追加・編集・削除できます。プリセットの変更は登録済みの豆名に影響しません。削除した初期プリセットが再起動で自動復活することもありません。

在庫のフィルターは一覧を往復する間は保持し、ページの再読み込みで「すべて」に戻ります。豆の新規登録後も、追加した豆を確認できるよう「すべて」に戻します。

1. 設定で「JSONを書き出す」を選び、ダウンロード先にファイルがあることを確認します。
2. 復元するときは「JSONから復元」でファイルを選びます。
3. 現在と復元後の在庫・アーカイブ・プリセット件数を比較します。必要なら現在のデータも書き出します。
4. 「全データを置き換えて復元」を押すと、既存データ全体を置き換えます。キャンセルでは変更されません。

不正な形式、未知のバージョン、重複ID、状態の不整合は反映前に拒否します。復元途中の中断は在庫とプリセット両方をロールバックします。空のバックアップの復元は全データ削除になるため、確認画面で明示します。JSONには全データが含まれるので、必要な場所に保管してください。

## ホーム画面への追加とGitHub Pages

PWAのmanifest・アイコン・standalone表示に対応しています。CSVとオフラインキャッシュは後回しにしたため、起動・再読み込みには通信が必要です。

公開URLは https://tanyeee.github.io/CoffeeStrage/ です。iPhoneのSafariで開き、共有メニューから「ホーム画面に追加」を選んでください。「Webアプリとして開く」が表示される場合は有効にします。ホーム画面のCoffeeアイコンから起動できます。

localhostと公開サイトは保存先が別です。移行前にローカル版の設定からJSONを書き出し、公開サイトの設定で復元してください。Safariとホーム画面起動でデータが見えない場合もJSONで移します。

mainへのpushでGitHub Actionsがテストを実行し、アプリファイルだけをGitHub Pagesへ配信します。初回はリポジトリのSettings → Pages → SourceをGitHub Actionsに設定します。`scripts/prepare-pages.mjs`が配信ファイルを`_site/`へコピーします。テスト・開発資料・依存パッケージは配信対象に入りません。
